# Ядро для интернет-магазина 

Краткое описание: *В данном проекте предполагается реализовать ядро для интернет-магазина.
Его можно будет использовать для создания полноценного сайта или телеграмм-бота*

Примечание: На текущий момент проект находится на стадии разработки и не имеет законченный вид.
Однако вы можете склонировать себе проект и поработать с текущим функционалом.

## ⚙️ Установка  
1. Клонируйте репозиторий:
```
git clone https://github.com/k0smax/online_store.git
```
2. Установите зависимости:

В этом проекте используется инструмент для управления зависимостями и сборкой пакетов в Python - `Poetry`
```
poetry install 
```

Установленные зависимости:

group.dev
- pytest (8.3.5)
- pytest-cov (6.0.0)

group.lint
- flake8 (7.2.0)
- black (25.1.0)
- isort (6.0.1)
- mypy (1.15.0)

Для добавления зависимостей вручную с помощью poetry необходимо выполнить следующую команду для каждой зависимости

```poetry add <наименование_зависимости>```

Версия Python - 3.13

## 🛠️ Функционал
Реализованы два класса:

`class Product` - класс, который описывает товары. Имеет следующие атрибуты (свойства):
- name - наименование продукта 
- description - описание продукта
- price - цена продукта
- quantity - количество штук продукта

`class Category` - класс, который описывает категории товаров. Имеет следующие атрибуты (свойства):
- name - наименование категории
- description - описание категории
- products - список продуктов в данной категорий (Каждый продукт - это объект класса `Product`)
- category_count - количество категорий (АТРИБУТ КЛАССА)
- product_count - количество товаров в целом (АТРИБУТ КЛАССА)
